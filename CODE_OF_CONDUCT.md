# Code of conduct

Treat contributors and users with respect. Discuss code and behaviour constructively, keep feedback specific, and welcome different experience levels and accessibility needs.

Harassment, discriminatory language, threats, sharing another person's private information, and repeated disruptive behaviour are not acceptable in project issues, pull requests or discussions. Maintainers may remove inappropriate content or limit participation to protect the community.

To report a conduct problem, use GitHub's reporting tools on the relevant content and identify the behaviour without republishing private information. For concerns suitable for a maintainer-visible project report, open an issue with only non-sensitive context.
