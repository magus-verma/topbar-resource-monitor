## 0.1.0 — 2026-10-07

- CPU, RAM and swap percentage indicators with green, amber, red and unavailable icons.
- Sustained usage warnings, critical escalation, recovery hysteresis and limited repeat notifications.
- Precise memory/swap capacity details and a session-wide warning mute switch.
- Optional System Monitor shortcut with support for multiple graphical monitors/terminals.
- Per-user installer, upgrade backups, preserved settings and uninstaller.
- Automatic graphical-session startup using systemd user services.
- Configuration validation, suspend-aware warning windows and disabled-swap handling.
- Real cropped screenshot, illustrated usage states and installation/troubleshooting documentation.
- Automated resource, alert and installation tests; CI on Python 3.10 and 3.14.

Desktop validation: Ubuntu 26.04.1 LTS, GNOME 50.1, Wayland, ARM64. Other desktop combinations are not yet verified.
