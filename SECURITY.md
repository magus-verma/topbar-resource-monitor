# Security policy

The latest tagged release is the supported version for fixes. This application runs as your desktop user and reads local resource counters. Its runtime does not contact external services. Distribution-provided Python/GTK/AppIndicator/notification libraries should be kept current through your distribution's package manager.

Report suspected vulnerabilities privately through [GitHub's Report a vulnerability form](https://github.com/magus-verma/topbar-resource-monitor/security/advisories/new). Include the affected release, relevant environment and reproduction steps. Avoid posting credentials or unrelated desktop screenshots. No response-time guarantee is offered for this small community project.

Use ordinary [issues](https://github.com/magus-verma/topbar-resource-monitor/issues) for usage questions and non-security bugs.
